# 便便日历（极简版）

只记录“哪一天排便了”。不记录时间、次数、Bristol 类型、症状或备注。

## 使用方式
- 首页点击「今天拉了」即可记录今天。
- 日历上直接点击任意日期，可补记或取消。
- 自动显示：近 30 天有记录的天数、平均记录间隔、距上次记录天数。
- 数据默认只保存在当前浏览器本地。
- 「数据备份」可导出 / 导入 JSON。

## iPhone 添加到主屏幕
把文件部署到任意 HTTPS 静态网页托管后，在 Safari 打开网页，点击分享 → 添加到主屏幕。

如果浏览器中已经使用过上一版 Gut Log，本版会自动把旧记录压缩为“日期集合”，不会继续显示详细字段。
